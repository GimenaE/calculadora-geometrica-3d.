# Calculadora Geométrica Analítica 3D

Aplicación web desarrollada en Python para visualizar,
modificar y analizar sólidos geométricos en tres dimensiones.

## Funcionalidades

- Visualización de esfera.
- Visualización de elipsoide.
- Construcción de prismas poligonales.
- Modificación interactiva de dimensiones.
- Cálculo de áreas y volúmenes.
- Gráficos 3D interactivos.

## Tecnologías utilizadas

- Python
- Streamlit
- NumPy
- Plotly
